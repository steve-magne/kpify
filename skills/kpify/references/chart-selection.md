# Chart selection

Pick the chart from the question, not from the data shape or novelty.

| Question | Chart | Notes |
|---|---|---|
| How does it change over time? | Line | Consistent time grain; mark partial periods |
| Which category is bigger? | Bar, sorted | Horizontal when labels are long; start at zero |
| What is it made of? | Stacked bar | Few parts (≤5); pie only for 2–3 parts of one whole |
| Are two measures related? | Scatter | Say "associated", not "causes" |
| How are values spread? | Histogram or box plot | Show n |
| Are we on track to a target? | Bullet or progress bar | Only with a supplied target |
| What is the exact value? | Table or single number | A chart is not always better |

## Avoid
- 3D, decorative gauges, rainbow palettes.
- Dual axes (use two aligned charts instead).
- Truncated bar axes. Line axes may start above zero if stated.
- More than ~6 series on one chart.
- Dashboards with charts that answer no named question.
